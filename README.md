### 👋 About me

I've spent my career in **ecommerce and digital marketing**, most recently as **Head of Ecommerce**. The parts I loved most were the autonomy, shipping features that had been proven by a CRO test, and arguing about PPC strategy.

In 2026 I stepped away from office life, spent most of the year travelling Asia, and came back wanting to **build things I own**. I'm not a developer by trade. I learn by doing, with AI as a pair-programmer, and this GitHub is where that work lives.

### 🖥️ The homelab: `mimiron`

My old gaming PC, reborn as a headless Ubuntu server. The goal: own my photos, run AI locally and keep a library that works offline.

<details open>
<summary><b>Hardware</b></summary>
<br/>

`Ryzen 7 2700X` · `64GB DDR4` · `RX 5700 XT (8GB)` · `Ubuntu Server 26.04 LTS` · NVMe + HDD split (app data on NVMe, backups on HDD)

</details>

| Service | Why it's there |
|---|---|
| 📸 **Immich** | Replaced Google Photos. Migrated ~48,000 photos and videos from Google Takeout. |
| 🦙 **Ollama + Open WebUI** | Local LLMs running on an AMD GPU via Vulkan. |
| 📚 **Project NOMAD** | Offline library: Kiwix (Wikipedia and more), Kolibri courses, UK maps and an AI assistant. |
| 📝 **CouchDB + Obsidian LiveSync** | Self-hosted note sync across Mac, Windows and phone. |
| 🔖 **Linkding** | Lightweight bookmark manager. |
| 🧭 **Glance** | Homepage dashboard: service tiles, RSS, weather, server stats, markets. |
| 📊 **Netdata · WUD · Dozzle** | Monitoring, container update alerts and logs. |
| 🔐 **Tailscale** | Secure access from anywhere, no open ports. |
| 💾 **Backups** | Daily cron job to a separate drive with 7-day rotation. |

**Up next:** Navidrome (goodbye Spotify), Uptime Kuma, and a self-hosted AI agent.
